# Changelog

## 0.1.5 — 2026-10-28

- Лицензия MIT: файл `LICENSE` (входит в архив релиза), поле `"license": "MIT"` в `plugin.json`, раздел «Лицензия» в README.
- Автопубликация: при push тега `v<версия>` GitHub Actions (`.github/workflows/release.yml`) прогоняет тесты, собирает
  архив `release.sh` и прикладывает его к GitHub Release. Код плагина не менялся.
- `plugin.json`: поле `"repository": "burzilov/motorchk-plugin-i18n"` — где искать обновления. Схема релизов
  фиксирована: тег `vX.Y.Z`, asset `i18n-X.Y.Z.zip` с папкой `i18n/` (внутри `plugin.json`). Ядро 0.5.6 поле не использует
  и игнорирует.

## 0.1.4 — 2026-10-27

- Совместимость с ядром motorchk 0.5 (`"core": "^0.5"`): ядро 0.5 с ограничением `^0.4` плагин не загрузило бы.
  Код не менялся.
- `build.sh` → `release.sh`: проверка чистого дерева и CHANGELOG, тег `v<версия>`, архив из тега.

## 0.1.3 — 2026-10-20

- Убран `Service::localized()` — он повторял `localized()` ядра. Значение по языку теперь берётся только из ядра:
  `$plugin->localized([...])` в плагинах, `SiteLocale::localized([...])` в темах (ядро ≥ 0.4.2). Правило то же:
  текущий язык → основной → первое непустое.

## 0.1.2 — 2026-10-20

- Чистка кода без изменения поведения: убран неиспользуемый `Settings::exists()`, лишняя обёртка
  `AdminController::dictionaryLocales()` (языки словаря — `Service::locales()`), `Service::switchHref()` стал
  внутренним (снаружи не вызывался), убран неиспользуемый `use PluginContext` в `Service`. Комментарий и пример
  в README про `?lang` — без отсылок к старым адресам customizer (сам `?lang=xx` — явный выбор языка — остаётся).

## 0.1.1 — 2026-10-20

- `settings.json` и `dictionary.json` читаются через `readJsonStrict()` ядра 0.4.0 вместо своей проверки
  `json_decode()`. Поведение прежнее: повреждённый файл не перезаписывается, сайт работает с настройками по
  умолчанию (пустым словарём), в админке — предупреждение, теперь с полным путём `plugin-data/i18n/…` и
  причиной (не JSON / не объект).

## 0.1.0 — 2026-10-20

- Служба `i18n` для ядра motorchk ≥ 0.4: `locale()`, `t()`, `localized()`, `url()`, `switcher()`, `names()`.
- Адреса `/en/…` для дополнительных языков, у основного языка префикса нет; `/ru/…` → 301 на адрес без префикса, `/en` → `/en/`.
- Определение языка: префикс адреса → cookie `site_locale` → Accept-Language (только первый визит на главную, выключено по умолчанию); `?lang=xx` — явный выбор.
- Переключатель языка: плавающий на всех страницах или вручную (`<!--i18n:switcher-->` в тексте, `$i18n?->switcher()` в теме).
- Внутренние ссылки в тексте страниц переписываются на текущий язык; подписи меню — из словаря (`menu.{slug}` или сама подпись).
- Админка «Языки»: список языков, основной язык, определение языка, переключатель; «Словарь»: строки интерфейса, импорт/экспорт JSON.
- Повреждённые `settings.json` / `dictionary.json` не перезаписываются молча — предупреждение в админке.
